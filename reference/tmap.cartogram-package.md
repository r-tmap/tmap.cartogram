# Extension for 'tmap': cartograms

New layer functions for 'tmap' to create cartograms: contiguous
cartograms
([`tm_cartogram()`](https://r-tmap.github.io/tmap.cartogram/reference/tm_cartogram.md)),
non-contiguous cartograms
([`tm_cartogram_ncont()`](https://r-tmap.github.io/tmap.cartogram/reference/tm_cartogram.md)),
and Dorling cartograms
([`tm_cartogram_dorling()`](https://r-tmap.github.io/tmap.cartogram/reference/tm_cartogram.md)).
See the article <https://r-tmap.github.io/tmap/articles/ext_cartogram>.
